## Nguyên tắc làm việc
- Toàn bộ thao tác tạo mới, chỉnh sửa file, thực hành code và demo diễn ra trong phạm vi thư mục `Github_kiet`.
- Các thư mục khác trong workspace (`BaoCao_LaTeX`, `Slide_LaTeX`, `Demo_ASPX`, `HinhAnh`,...) ở chế độ **Chỉ đọc (Read-Only)** để tham khảo ngữ cảnh chung của nhóm.
