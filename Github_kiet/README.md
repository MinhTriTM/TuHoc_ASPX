# Không gian làm việc cá nhân (Github_kiet)

Thư mục này dành riêng cho việc thực hành, ghi chép và triển khai các nội dung bài tập, demo và tài liệu của **Kiệt** trong khuôn khổ đề tài **GIT – GitHub – GitLab cho học phần ASPX (.NET Framework 4.8.1)**.

## Tài liệu hiện có
- [progit.pdf](file:///T:/HK1_26_27/Lap_trinh_aspx/TuHoc_ASPX/Github_kiet/progit.pdf): Sách Pro Git (Scott Chacon & Ben Straub).

## Nguyên tắc làm việc
- Toàn bộ thao tác tạo mới, chỉnh sửa file, thực hành code và demo diễn ra trong phạm vi thư mục `Github_kiet`.
- Các thư mục khác trong workspace (`BaoCao_LaTeX`, `Slide_LaTeX`, `Demo_ASPX`, `HinhAnh`,...) ở chế độ **Chỉ đọc (Read-Only)** để tham khảo ngữ cảnh chung của nhóm.
